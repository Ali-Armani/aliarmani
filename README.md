# Ali Armani — Portfolio

Personal portfolio in English and German. Pages: home, work, five project pages,
about, skills, résumé and contact.

Stack: TanStack Start (React 19), TypeScript, Tailwind CSS v4.

## Getting started

Requires Node.js 22 or newer.

```sh
npm install
npm run dev
```

The dev server runs on http://localhost:5173 by default.

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run build`   | Production build             |
| `npm run preview` | Preview the production build |
| `npm test`        | Run tests (Vitest)           |
| `npm run lint`    | Run ESLint                   |
| `npm run format`  | Format with Prettier         |

## Structure

```text
src/
  routes/       one file per page, __root.tsx is the shared layout
  components/   header, footer and page sections
  content/      profile and project data
  i18n/         English and German texts
  assets/       project screenshots
public/         favicon, robots.txt, résumé PDF
```

`src/routeTree.gen.ts` is generated by the router. Do not edit it.

## Notes

- The résumé page links to `public/assets/Ali-Armani-Resume.pdf`. If the file is
  missing, the page shows a note to request it by email.
- The selected language is stored in the visitor's browser.
- The site needs no API keys or database.

## Deployment

The site is deployed on Vercel.
